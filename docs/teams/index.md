# Teams

Rocky Linux has many diverse teams, each with their own important work. The **Teams** location within this site, attempts to gather the public-facing documentation from these teams beneath a single umbrella. If you are in search of specific information and cannot find it here, let us know. A general message on [the Documentation channel chat](https://chat.rockylinux.org/rocky-linux/channels/documentation) with the information you are looking for, should work.

Please note that the consolidation of public-facing documentation is on-going as of 29 July, 2026, so some information is not yet moved.
