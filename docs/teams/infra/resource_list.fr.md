Ces ressources sont partagées avec l'équipe Infrastructure.

## Services des comptes

C'est là que vous créez et gérez votre compte Rocky Linux et que vous signez les contrats.

- URL : [Account services](https://accounts.rockylinux.org)
- Technologie : Noggin utilisé par l'infrastructure Fedora.
- Contact : [Infrastructure dans Mattermost](https://chat.rockylinux.org/rocky-linux/channels/infrastructure) et `#rockylinux-infra` dans Libera IRC.

## Service Git de RESF

Projets généraux, codés et plus encore pour la Rocky Enterprise Software Foundation (RESF).

- URL : [Git service](https://git.resf.org)
- Technologie: [Forgejo](https://forgejo.org)
- Contact : [Infrastructure](https://chat.rockylinux.org/rocky-linux/channels/infrastructure) ou [Development](https://chat.rockylinux.org/rocky-linux/channels/development) dans Mattermost et `#rockylinux-infra` ou `#rockylinux-devel` dans Libera IRC.

## Rocky Linux GitLab

Paquets et code léger pour la distribution Rocky Linux.

- URL : [Rocky GitLab](https://git.rockylinux.org)
- Technologie : [GitLab](https://gitlab.com)
- Contact : [Infrastructure](https://chat.rockylinux.org/rocky-linux/channels/infrastructure) ou [Development](https://chat.rockylinux.org/rocky-linux/channels/development) dans Mattermost et `#rockylinux-infra` ou `#rockylinux-devel` dans Libera IRC.

## Services de miroirs

Demande permettant aux utilisateurs de devenir un serveur miroir pour le contenu Rocky, que ce soit pour le système d'exploitation ou pour les contenus SIG.

- URL: [Mirror services](https://mirrors.rockylinux.org)
- Technologie : MirrorManager 2
- Contact: [Infrastructure](https://chat.rockylinux.org/rocky-linux/channels/infrastructure) dans Mattermost et `#rockylinux-infra` dans Libera IRC.
- etc...
