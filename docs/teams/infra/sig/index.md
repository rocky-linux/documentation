## SIGs defined

Special Interest Groups or SIGs, provide a method for interested users to extend the Enterprise Linux experience with packages, images, or community engagement. Think of SIGs as a place within the larger Rocky Linux community where like-minded users can gather around a shared interest.

## Requirements for Rocky Linux SIGs

* The SIG should relate to the Rocky Linux project or Enterprise Linux
* All communications are public
* The expectation is that a Mattermost channel exist within [chat.rockylinux.org](https://chat.rockylinux.org)
* The production of code within the SIG should follow, or be compatible with, the FOSS license that Rocky Linux uses
* The production of documentation within the SIG should be public-facing under the [Documentation](https://docs.rockylinux.org) umbrella
* SIGs may keep code created in their own [RESF resource](https://git.resf.org)
* SIGs should be aware of the direction Release Engineering is taking to ensure that code produced follows a similar philosophy

## SIG membership

* SIG members are appointed or approved by SIG sponsors or leaders
