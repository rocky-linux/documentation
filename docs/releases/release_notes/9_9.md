## Release notes for Rocky Linux 9.9

## Upgrading

You can upgrade from Rocky Linux 9.x to Rocky Linux 9.9 by running `sudo dnf -y upgrade`.

!!! Note

    Rocky Linux does not offer an upgrade path from any version of Rocky Linux 8. We recommend that you perform a fresh OS installation to upgrade to Rocky Linux 9.9.

## Installing

Before installing, [ensure compatibility of your CPU with this procedure!](../../gemstones/test_cpu_compat.md)

To install Rocky Linux 9.9, go to the [download page](https://rockylinux.org/download/) and download the version corresponding to your architecture.

## Major changes

This document highlights major changes between Rocky Linux (RL) 9.8 and RL 9.9. If this is your first time migrating to RL 9, you might want to review the release notes for previous versions to get a feel for all the changes you will encounter.

For a complete list of major changes, see the [upstream listing here](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/9/html/9.9_release_notes/new-features).

### Security

Listed below are security-related highlights in the latest RL 9.9:

- Keylime is rebased to 7.14.3
- `keylime-agent-rust` is rebased to 0.2.10
- `fapolicyd` is rebased to 2.0.1 with a host of enhancements and bug fixes
- `opencryptoki` is rebased to 3.27.0
- A new `sequoia-sq` package providing `sq` command-line tool to read and inspect OpenPGP certificates
- OpenSSL startup self-check removed, with verification of the SSL certificates handled by the peer during handshake
- SELinux policy supports BIND bind packages with suffixes
- Custom SELinux context `hid_sensor_device_t` available for HID-SENSOR devices
- Enhanced `rsyslog` statistics integration with Zabbix and granular `imkafka` metrics
- GnuTLS TLS driver in `rsyslog` enforces CRL expiration
- The `rsyslog omelasticsearch` module supports configurable TLS parameters
- Pre-configured `systemd` timer for automated Advanced Intrusion Detection Environment (AIDE) integrity checks
- `aide` supports drop-in configuration files placed in the `/etc/aide.d` directory
- `fapolicyd` packages rebased to upstream version 1.4.3, providing filtering rules

### Kernel

- New `kernel` `sysctl` parameters to control memory reclaim aggressiveness
- Custom extended Berkeley Packet Filter (eBPF) program execution in Real-Time Linux Analysis (RTLA) framework
- The `ima-evm-utils` package extends Integrity Measurement Architecture (IMA) to previously unevaluated files systems (`/proc`, `/sysfs`, `/tmp`)
- `libzpc` version 2 packages available to support security features on new IBM Z systems
- Memory System Resource Partitioning and Monitoring (MPAM) now supports virtual machines on ARM

### Infrastructure services

- `cyrus-imapd reconstruct` now has the `--fix-uidvalidity` option
- PHP 8.4 available
- SystemTap is rebased to version 5.5
- `elfutils` includes new enhancements across debugging and analysis tools (see upstream for complete list)
- Valgrind is rebased to 3.27.1

### Software management

- `reposync` supports new `--min-buildtime` option
- DNF preserves POSIX Access Control Lists (ACLs) on rotating `dnf.log` file

### Containers

- The podman system service command supports TLS and mutual TLS (mTLS) encryption and client client authentication for TCP sockets
- `podman-py` supports setting startup health check options during container creation
- The container tools meta packages have been updated
- New container images are now available (`ubi9/dotnet-110`, `ubi9/dotnet-110-aspnet`, and `ubi9/dotnet-110-runtime`)
- Backend of `bootc-image-builder` migrated to `image-builder-cli`

### Compilers and development tools

- `gdb` package is rebased to 17.2
- LLVM Toolset is rebased to 22.1.8
- `rust` is rebased to 1.97
- `gcc-toolset-16` package is available providing recent stable versions of development tools. This includes the `gcc-toolset-16-gcc`, and the `gcc-toolset-16-binutils` packages
- Improved performance of string memory functions on AMD Zen 5 processors

### Networking

- `bind` is rebased to 9.16.50
- The updated `iproute` package contains the `ip link` command supporting the display of High-availability Seamless Redundancy (HSR) protocol version configured on an interface
- TCP Authentication Option (TCP-AO), a more secure authentication method, is now supported allowing for the deprecation of the less-secure TCP-MD5 authentication
- `sendmail-milter` has moved from the CodeReady Builder repository (CRB) to the Appstream repository
- The `nmcli` can now configure interfaces as managed or unmanaged
- NMState supports IPv4 over IPv4 (IPIP), IPv4 over IPv6 (IPIP6), IPv6 over IPv6 (IP6IP6), or Simple Internet Transition (SIT)
- The `zl3073x` Digital Phase Locked Loop (DPLL) driver, now rebased to version 7.1, supports precise phase synchronization

### High availability and clusters

- new `pcs` commands simplify the cluster node renaming workflow
- `pcs` also validates resources and fencing operations during updates and additions
- `sybaseASE` resource agent requires you to explicitly configure the `sybase_ase` parameter instead of auto-detecting from the `SYBASE.env` file
- `nfsserver` resource agent actively monitors the `rpc.mountd` and `nfsdcld` processes, in addition to the `nfs-server.service` unit
- the `fence_vmware_rest` agent supports token-based authentication as an alternative to password-based authentication

### Identity management

- improved large group membership lookups where members belonged to a great number of groups
- SSSD supports mapping Active Directory AMA SIDs to authentication indicators
- `python-qrcode` is rebased to 8.0
- `openldap` is rebased to 2.6.13
- `python-jwcrypto` is rebased to 1.5.7
- `389-ds-base` is rebased to 2.9.0
- Directory Server threads have OS-visible names for diagnostics
- `python-ldap` is rebased to 3.4.7
- `python-pyasn1` is rebased to 0.6.4
- The Lightning Memory Mapped Database (LMDB) backend in Directory Server is fully supported
- `ipa` is rebased to 4.13.4
- The `ipauser` and `ipagroup` modules in the `ansible-freeipa` package supports a new query state for lookups that retrieves information about Identity Management (IdM) users and groups without modifying them

### SSSD

- `authselect` disables group merging by default

### Web console

- `cockpit` is rebased to 366
- the `MaxConcurrentConnections` option is available

## Known issues

As with any release, there are many known issues. Review the [upstream listing](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/9/html/9.9_release_notes/known-issues) for the complete details on these issues.

!!! info "Deprecated Software"

    Some Application Streams, which are part of the Rocky Linux 9.9 repositories, will not receive any further updates. This is a regular occurrence that happens with nearly every release. Please make sure that you are using the latest supported version of the software.
