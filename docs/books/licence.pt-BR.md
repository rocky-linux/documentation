# Licença

O Rocky Linux oferece material didático sobre Linux para instrutores e para pessoas que desejam aprender a administrar um sistema Linux por conta própria.

Os materiais do Rocky Linux são publicados sob a licença Creative Commons BY-SA. Isso significa que você livre para compartilhar e adaptar o material, desde que respeite os direitos do autor.

**BY** : **Atribuição**. Você deve citar o nome do autor original.

**SA** : **Compartilhar Pela Mesma Licença**.

- Licença Creative Commons-BY-SA: https://creativecommons.org/licenses/by-sa/4.0/

Os documentos e seus respectivos arquivos-fonte podem ser baixados livremente em:

- [https://docs.rockylinux.org](https://docs.rockylinux.org/)
- [https://github.com/rocky-linux/documentation](https://github.com/rocky-linux/documentation)

Nossos arquivos de mídia são hospedados no GitHub. Você encontrará o repositório do código-fonte onde esta versão do documento foi criada.

A partir desses arquivos-fonte, você pode gerar seu próprio material didático personalizado utilizando [mkdocs](https://www.mkdocs.org/). Você encontrará as instruções para gerar o seu documento [aqui](https://github.com/rocky-linux/documentation/tree/main/build_pdf).

> Como eu posso contribuir para o projeto de documentação?

Você encontrará todas as informações necessárias para se juntar a nós na [página inicial do nosso projeto no git](https://github.com/rocky-linux/documentation).

Desejamos a todos uma excelente leitura e esperamos que aproveitem o conteúdo.
